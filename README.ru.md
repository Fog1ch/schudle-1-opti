# Schedule I Performance Lab

Внешний инструмент для конкретной исследованной установки. Не runtime-мод, не DLL-инжектор. На момент поставки игра и настройки не изменены.

## Состав

- `REPORT.ru.md`: технический отчёт.
- `s1lab.py`: read-only аудит, подготовка, точечное применение и откат профилей.
- `static_inventory.py`: ограниченный Unity v22/IL индексатор; использует существующий локальный ILSpy по фиксированному пути. Для применения профилей не нужен.
- `test_integration.py`: тестирование на искусственных файлах, без игры.
- `evidence/audit.json`: инвентаризация и fingerprint установки.
- `evidence/assets.json`: карта сериализованных объектов ресурсов.
- `evidence/mod-analysis.json`: ограниченный IL-анализ, не гарантия совместимости.
- `evidence/S1Perf.installed.cs`, `ScheduleRu.installed.cs`: декомпиляция установленных модов для локального исследования. Не выдаются за авторские исходники или готовые проекты сборки.
- `profiles/*/original.cfg`: резервная копия конфигурации до эксперимента.
- `profiles/*/candidate.cfg`: предлагаемая конфигурация.
- `profiles/*/changes.diff`, `manifest.json`: точный diff и контрольные суммы.
- `verification.json`, `tests.txt`, `SHA256SUMS.txt`: итоговая проверка поставки.

## Профили

1. `ui-scan`: `CanvasScanInterval` 0.0 → 0.05. Первый рекомендуемый эксперимент: без уменьшения графического качества, но с возможной задержкой обнаружения нового текста.
2. `quiet-translation`: `DumpUntranslated` true → false. Прекращает сбор неизвестных строк, не отключает перевод.
3. `texture-2560`: `TextureBudgetMB` 8000 → 2560. Только эксперимент, не оптимальный или жёсткий VRAM-лимит. Возможны mip pop-in, снижение детализации и дополнительные подгрузки. Выполнять отдельно.

**Профили не применены.** Применение только после чтения отчёта, diff и осознанного подтверждения. Проверки тестов не заменяют игровой тест. Не применяйте их во время игры, загрузки/обновления игры или редактирования настроек другим процессом.

## Применение одного профиля

Пример для `ui-scan`, не выполненный при подготовке:

```bat
python s1lab.py apply --package profiles\ui-scan --confirm
```

Инструмент проверяет отсутствие процесса игры, fingerprint шести ключевых компонентов, оригинал и кандидат, разрешённый единственный ключ и исходный хэш настроек. Затем заменяет только `UserData\MelonPreferences.cfg` и проверяет результат. Сохранения и бинарники не меняются. После изменения игра сама не запускается.

Если DLL/игра или конфигурация изменились, инструмент откажется от перезаписи. Не отключайте защиту и не обновляйте хэши вручную. Нужны повторный аудит и подготовка совместимого пакета. Проверка процесса уменьшает риск, но не блокирует запуск игры другим приложением после проверки.

## Откат

Закройте игру, не запускайте её во время операции:

```bat
python s1lab.py rollback --package profiles\ui-scan --confirm
```

Восстанавливается byte-for-byte исходная конфигурация данного профиля. Для остальных укажите соответствующую папку. Если игра успела переписать конфигурацию или пользователь внёс другие изменения, автоматический откат остановится. Тогда сравните текущий файл с `changes.diff` и восстановите только изменённый ключ, не затирая прочие новые настройки. `original.cfg` остаётся доступной резервной копией.

Профили независимые и подготовлены от одной базы: применить один, проверить, откатить, затем другой. Автоматическое объединение запрещено. После обновления игры старый пакет не предназначен для принудительного применения.

## Удаление

Если ничего не применяли, откат игры не нужен. Пакет можно оставить для исследования. Если профиль применён, сначала откатите его и убедитесь в восстановлении; сохраняйте резервные копии до завершения проверки. Установка игры не зависит от этой папки.

## Чего пакет не делает

Не запускает игру, не изменяет сохранения, Steam/DRM или системные настройки, не правит boot.config, не декодирует всю ресурсную базу, не управляет VRAM в реальном времени, не обещает FPS и не доказывает отсутствие конфликтов модов.
